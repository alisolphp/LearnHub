## [Tema 1: Introducción a AWS]

* **Resumen**: Esta sección comienza con una visión general de cómo acercarse a AWS, comparándolo con una nave espacial con distintos servicios. Cubre los objetivos del curso, como entender los servicios clave, sus iconos y cuándo utilizarlos, además de los prerrequisitos, como conocimientos básicos de informática y redes.
* **Ejemplo**: Piensa en tu cuenta de AWS como el Millennium Falcon para equipos pequeños o la Starship Enterprise para operaciones más grandes, ayudándote a visualizar la escala y la gestión.
* **Enlace para más detalles**: [Ask AI: Introducción a AWS](https://alisol.ir/?ai=Introduction%20to%20AWS%7CJeremy%20Villeneuve%7CAWS%20Essential%20Training%20for%20Developers|es)

## [Tema 2: Configuración de la cuenta de AWS y seguridad]

* **Resumen**: Aprenderás a configurar una root account de AWS, crear usuarios IAM para un acceso más seguro, generar API keys y configurar billing alarms para evitar sorpresas. Se hace hincapié en proteger la root account con MFA y en seguir el principio de least privilege.
* **Ejemplo**: Después de crear un usuario IAM y añadirlo a un grupo "admins" con AdministratorAccess, cierras sesión de la root account y utilizas ese usuario IAM para las tareas diarias, como si el capitán delegara el mando rutinario.
* **Enlace para más detalles**: [Ask AI: Configuración de la cuenta de AWS y seguridad](https://alisol.ir/?ai=AWS%20Account%20Setup%20and%20Security%7CJeremy%20Villeneuve%7CAWS%20Essential%20Training%20for%20Developers|es)

## [Tema 3: Fundamentos de cloud computing]

* **Resumen**: Explora los retos del hosting on‑premise antes de la nube, el lanzamiento de EC2 para servidores elásticos y de S3 para almacenamiento, el uso de regions y availability zones para redundancia, y el shared responsibility model, donde AWS gestiona el hardware y tú te encargas de la seguridad del software.
* **Ejemplo**: Antes de la nube, escalar para picos de tráfico repentinos podía requerir semanas de preparación de hardware; con EC2 auto scaling, los servidores se expanden de forma elástica durante un pico de tráfico del fin de semana y vuelven a reducirse el lunes.
* **Enlace para más detalles**: [Ask AI: Fundamentos de cloud computing](https://alisol.ir/?ai=Cloud%20Computing%20Fundamentals%7CJeremy%20Villeneuve%7CAWS%20Essential%20Training%20for%20Developers|es)

## [Tema 4: Instancias EC2 y almacenamiento]

* **Resumen**: Guía el proceso de crear instancias EC2, elegir instance types según la carga de trabajo (por ejemplo, general purpose), adjuntar EBS volumes para almacenamiento persistente y usar Elastic IPs para disponer de direcciones estáticas.
* **Ejemplo**: Lanza una instancia t2.micro con Ubuntu, conéctate por SSH usando un key pair y adjunta un EBS volume como si añadieras un disco externo para guardar datos de la app más allá de la vida de la instancia.
* **Enlace para más detalles**: [Ask AI: Instancias EC2 y almacenamiento](https://alisol.ir/?ai=EC2%20Instances%20and%20Storage%7CJeremy%20Villeneuve%7CAWS%20Essential%20Training%20for%20Developers|es)

## [Tema 5: Networking en AWS]

* **Resumen**: Cubre VPCs, subnets para acceso público/privado, load balancers para distribuir tráfico, CloudFront como CDN para caching y Route 53 para DNS management, asegurando una conectividad fiable.
* **Ejemplo**: Configura una VPC con public subnets para los servidores web y private subnets para las bases de datos, y utiliza un Application Load Balancer para distribuir el tráfico de forma uniforme, como dirigir barcos a distintos muelles.
* **Enlace para más detalles**: [Ask AI: Networking en AWS](https://alisol.ir/?ai=Networking%20in%20AWS%7CJeremy%20Villeneuve%7CAWS%20Essential%20Training%20for%20Developers|es)

## [Tema 6: Soluciones de almacenamiento avanzadas]

* **Resumen**: Explica S3 para object storage, Glacier para archivado, Snowball para transferencias masivas de datos, EFS para file systems compartidos y storage gateways para escenarios hybrid cloud.
* **Ejemplo**: Utiliza S3 para alojar archivos estáticos con buckets públicos para un sitio web, o usa Snowball para enviar terabytes de datos a AWS en lugar de subirlos lentamente por internet.
* **Enlace para más detalles**: [Ask AI: Soluciones de almacenamiento avanzadas](https://alisol.ir/?ai=Advanced%20Storage%20Solutions%7CJeremy%20Villeneuve%7CAWS%20Essential%20Training%20for%20Developers|es)

## [Tema 7: Servicios de bases de datos]

* **Resumen**: Desde ejecutar bases de datos en EC2 hasta usar RDS/Aurora gestionados para datos relacionales, DynamoDB para NoSQL, ElastiCache para caching, Redshift para big data warehousing y Athena para consultar data lakes en S3.
* **Ejemplo**: Crea una instancia RDS MySQL para los datos de usuarios de una web app, escalando de forma sencilla, o utiliza DynamoDB para almacenamiento key‑value en una app de alto tráfico con global tables para replicación.
* **Enlace para más detalles**: [Ask AI: Servicios de bases de datos](https://alisol.ir/?ai=Database%20Services%7CJeremy%20Villeneuve%7CAWS%20Essential%20Training%20for%20Developers|es)

## [Tema 8: Servicios de mensajería y plataforma]

* **Resumen**: Presenta Kinesis/SQS/SNS para colas y mensajería, Elastic Beanstalk para despliegue sencillo de aplicaciones y Lightsail para hosting simple similar a los proveedores tradicionales.
* **Ejemplo**: Usa SQS para encolar tareas de generación de informes durante los picos de uso, evitando sobrecargar la base de datos, o despliega un sitio WordPress mediante Elastic Beanstalk para tener actualizaciones gestionadas sin tocar servidores.
* **Enlace para más detalles**: [Ask AI: Servicios de mensajería y plataforma](https://alisol.ir/?ai=Messaging%20and%20Platform%20Services%7CJeremy%20Villeneuve%7CAWS%20Essential%20Training%20for%20Developers|es)

## [Tema 9: Containers y serverless computing]

* **Resumen**: Explica ECS/Fargate para containers, ECR como container registry, Lambda para funciones serverless y Batch/Step Functions para jobs de procesamiento y workflows.
* **Ejemplo**: Ejecuta un microservice en containers de ECS para tener escalabilidad o dispara una función Lambda cuando se suben archivos para redimensionar imágenes sin gestionar servidores.
* **Enlace para más detalles**: [Ask AI: Containers y serverless computing](https://alisol.ir/?ai=Containers%20and%20Serverless%20Computing%7CJeremy%20Villeneuve%7CAWS%20Essential%20Training%20for%20Developers|es)

## [Tema 10: Servicios SaaS]

* **Resumen**: Cubre Cognito para autenticación de usuarios, API Gateway/AppSync para backends, SageMaker y los ML APIs para inteligencia, MediaConvert para vídeo e IoT Core para gestión de dispositivos.
* **Ejemplo**: Integra Cognito para logins seguros con Google/Facebook o utiliza Rekognition para detectar caras en fotos subidas como funcionalidad extra en una app social.
* **Enlace para más detalles**: [Ask AI: Servicios SaaS](https://alisol.ir/?ai=SaaS%20Services%7CJeremy%20Villeneuve%7CAWS%20Essential%20Training%20for%20Developers|es)

## [Tema 11: DevOps en AWS]

* **Resumen**: Define DevOps como el puente entre development y operations, con CodePipeline para CI/CD, CloudFormation para infrastructure as code y CloudWatch para monitoring de rendimiento más allá del simple uptime.
* **Ejemplo**: Configura un pipeline que despliegue automáticamente cambios de código desde GitHub a ECS después de pasar los tests, asegurando lanzamientos rápidos sin intervención manual.
* **Enlace para más detalles**: [Ask AI: DevOps en AWS](https://alisol.ir/?ai=DevOps%20in%20AWS%7CJeremy%20Villeneuve%7CAWS%20Essential%20Training%20for%20Developers|es)

## [Tema 12: Seguridad en AWS]

* **Resumen**: Habla de WAF/Shield como firewalls, Inspector/GuardDuty/Macie para análisis y detección de amenazas, y CloudTrail/Security Hub para auditorías y monitoring centralizado.
* **Ejemplo**: Activa GuardDuty para detectar comportamientos inusuales en tus servidores, como conexiones de red extrañas, actuando como un guardia virtual contra compromisos internos.
* **Enlace para más detalles**: [Ask AI: Seguridad en AWS](https://alisol.ir/?ai=Security%20in%20AWS%7CJeremy%20Villeneuve%7CAWS%20Essential%20Training%20for%20Developers|es)

## [Tema 13: Conclusión]

* **Resumen**: Cierra con consejos de limpieza para evitar cargos innecesarios, recursos como blogs y eventos de AWS para mantenerte al día y recomendaciones sobre certificaciones acompañadas de proyectos prácticos.
* **Ejemplo**: Después de las demos, termina las instancias EC2 que ya no usas y borra los S3 buckets de prueba para mantenerte dentro de los límites del free tier y evitar facturas sorpresa.
* **Enlace para más detalles**: [Ask AI: Conclusión](https://alisol.ir/?ai=Conclusion%7CJeremy%20Villeneuve%7CAWS%20Essential%20Training%20for%20Developers|es)
