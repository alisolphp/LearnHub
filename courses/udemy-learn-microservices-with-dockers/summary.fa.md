## موضوع ۱: معرفی دوره

* **خلاصه**: در این دوره، از سطح خیلی مقدماتی شروع می‌کنی و قدم‌به‌قدم به جایی می‌رسی که بتوانی با استفاده از Docker یک اپلیکیشن کامل مبتنی بر microservices بسازی. تمرکز دوره روی توسعه microservices با تأکید بر مقیاس‌پذیری، انعطاف‌پذیری و سناریوهای واقعی است. استک‌ها و تکنولوژی‌هایی مثل HTML/CSS/JS، React، Node.js، PHP، Flask، RESTful API، MySQL و MongoDB پوشش داده می‌شوند. مدرس که بیش از هشت سال سابقه تدریس و برنامه‌نویسی دارد، روی حوزه‌های microservices، DevOps و cloud-native تمرکز دارد.
* **مثال**: تصور کن هیچ آشنایی قبلی با microservices نداری و در پایان دوره یک اپ e-commerce با چندین سرویس در زبان‌های مختلف می‌سازی که همگی containerized شده‌اند؛ این دقیقاً مسیری است که این دوره برایت ترسیم می‌کند.
* **لینک برای جزئیات بیشتر**: [Ask AI: Introduction to the Course](https://alisol.ir/?ai=Introduction%20to%20the%20Course%7CUsama%20Sharif%7CLearn%20Microservices%20with%20Dockers%20%28A%20Project%20Based%20Learning%29|fa)

## موضوع ۲: پیش‌نیازها و انگیزه

* **خلاصه**: برای شروع، فقط به یک آشنایی پایه با برنامه‌نویسی وب نیاز داری؛ مثلاً در PHP، Node.js یا حتی فقط HTML/CSS/JS. در حد این‌که یک برنامه ساده «Hello World» نوشته باشی هم کافی است. در این دوره توضیح داده می‌شود که چرا شرکت‌های بزرگی مثل Netflix، Uber، Amazon، Twitter، LinkedIn و Google از معماری monolithic به معماری microservices مهاجرت کرده‌اند تا مقیاس‌پذیری، کارایی و سرعت توسعه‌شان را بالا ببرند، و مثال‌های واقعی از این تغییر معماری آورده می‌شود.
* **مثال**: اگر تا حالا فقط یک صفحه وب ساده ساخته‌ای، همین هم برای شروع کافی است؛ مثل این‌که Uber بعد از رفتن به سمت microservices بتواند بدون مشکل درخواست‌های میلیون‌ها کاربر در سراسر دنیا را هندل کند.
* **لینک برای جزئیات بیشتر**: [Ask AI: Prerequisites and Motivation](https://alisol.ir/?ai=Prerequisites%20and%20Motivation%7CUsama%20Sharif%7CLearn%20Microservices%20with%20Dockers%20%28A%20Project%20Based%20Learning%29|fa)

## موضوع ۳: ساختار دوره و آماده‌سازی محیط

* **خلاصه**: ساختار دوره در سه فاز اصلی تقسیم شده است: (۱) مبانی تئوری (آشنایی با microservices، تحلیل و طراحی، و مفاهیم توسعه)، (۲) پیاده‌سازی عملی با Docker (containerize کردن اپ‌ها، کار با volumes، networks و Docker Compose)، و (۳) یادگیری مبتنی بر پروژه (سه پروژه واقعی). در ابتدای دوره، نصب Docker، VS Code و دریافت resourceهای دوره توضیح داده می‌شود و این‌که Docker چطور مشکل معروف «روی سیستم من کار می‌کند!» را با استفاده از containerهای سبک در مقابل virtual machineهای سنگین حل می‌کند.
* **مثال**: در فاز اول با مقایسه معماری‌ها و اصول طراحی آشنا می‌شوی؛ در فاز سوم یک اپ e-commerce می‌سازی که شامل هفت microservice در زبان‌هایی مثل Flask، React، Node.js و PHP است و به شش دیتابیس مختلف متصل می‌شود.
* **لینک برای جزئیات بیشتر**: [Ask AI: Course Structure and Setup](https://alisol.ir/?ai=Course%20Structure%20and%20Setup%7CUsama%20Sharif%7CLearn%20Microservices%20with%20Dockers%20%28A%20Project%20Based%20Learning%29|fa)

## موضوع ۴: معماری Monolithic و Modular

* **خلاصه**: در ابتدا با معماری سنتی monolithic آشنا می‌شوی؛ جایی که همه چیز (UI، منطق تجاری و دیتابیس) در یک واحد یکپارچه قرار دارد. این مدل برای اپ‌های کوچک قابل‌قبول است، اما در مقیاس بزرگ مشکلاتی مثل coupling بالا، سخت بودن تست و نگه‌داری، و دشواری در توسعه features جدید را ایجاد می‌کند. معماری modular این شرایط را بهتر می‌کند و اپ را به ماژول‌های مستقل تقسیم می‌کند که دیتابیس مشترک دارند اما وابستگی کمتری به هم دارند و تست و توسعه را انعطاف‌پذیرتر می‌کنند.
* **مثال**: در یک اپ e-commerce monolithic، تغییر در UI ممکن است باعث اختلال در بخش پرداخت شود. در معماری modular، اپ به ماژول‌های محصول، سفارش، پرداخت و ارسال تقسیم می‌شود و هر کدام را می‌توان تا حد زیادی مستقل به‌روزرسانی کرد.
* **لینک برای جزئیات بیشتر**: [Ask AI: Monolithic and Modular Architectures](https://alisol.ir/?ai=Monolithic%20and%20Modular%20Architectures%7CUsama%20Sharif%7CLearn%20Microservices%20with%20Dockers%20%28A%20Project%20Based%20Learning%29|fa)

## موضوع ۵: آشنایی با Docker و Containerization

* **خلاصه**: در این بخش می‌بینی که Docker در سال ۲۰۱۳ معرفی شد تا اپلیکیشن‌ها را در containerهای ایزوله اجرا کند و از سربار زیاد virtual machineها جلوگیری کند. یاد می‌گیری که چطور اپ‌هایی مثل Python، Java، Ruby و Go را داخل container اجرا کنی، volumes را mount کنی، از Docker Hub image بگیری و با دستوراتی مثل `docker run`, `docker ps`, `docker rm` containerها و imageها را مدیریت کنی.
* **مثال**: یک اپ Python را از سیستم خودت روی مسیر `/app` به داخل container mount می‌کنی، image سبک `python:3.8-slim` را از Docker Hub می‌گیری و با دستور `python /app/app.py` اجرا می‌کنی؛ بدون این‌که اهمیتی داشته باشد روی چه سیستمی هستی، رفتار اپ یکسان می‌ماند.
* **لینک برای جزئیات بیشتر**: [Ask AI: Introduction to Docker and Containerization](https://alisol.ir/?ai=Introduction%20to%20Docker%20and%20Containerization%7CUsama%20Sharif%7CLearn%20Microservices%20with%20Dockers%20%28A%20Project%20Based%20Learning%29|fa)

## موضوع ۶: Docker Volumes، Networks و Compose

* **خلاصه**: در این بخش با volumes برای نگه‌داری داده‌های persistent آشنا می‌شوی (تفاوت bind mount و named volume)، با شبکه‌ها (networks) برای ارتباط containerها با هم، و با Docker Compose برای مدیریت اپ‌های چند-containerی از طریق فایل YAML. در YAML می‌توانی سرویس‌ها، build، ports، networks و وابستگی‌ها را تعریف کنی تا کل سیستم به‌صورت یک جا بالا بیاید.
* **مثال**: در یک فایل YAML، یک سرویس frontend (مثلاً Nginx) و یک سرویس backend (مثلاً PHP/Apache) را روی یک network تعریف می‌کنی؛ با استفاده از volumes کد را از سیستم خودت mount می‌کنی تا بدون نیاز به build مجدد، تغییرات PHP را بلافاصله در مرورگر ببینی.
* **لینک برای جزئیات بیشتر**: [Ask AI: Docker Volumes, Networks, and Compose](https://alisol.ir/?ai=Docker%20Volumes%2C%20Networks%2C%20and%20Compose%7CUsama%20Sharif%7CLearn%20Microservices%20with%20Dockers%20%28A%20Project%20Based%20Learning%29|fa)

## موضوع ۷: پروژه ۱ – اپلیکیشن PHP و MySQL

* **خلاصه**: در این پروژه یک اپ سه-microservice می‌سازی: یک frontend (HTML/JS/CSS روی Nginx)، دو backend مبتنی بر PHP (یکی برای insert و یکی برای retrieve داده) و یک دیتابیس MySQL به‌همراه phpMyAdmin. با Dockerfileها و Docker Compose کل سیستم را orchestration می‌کنی و جریان داده بین containerها را می‌بینی.
* **مثال**: frontend دکمه‌هایی دارد که به backendها متصل شده‌اند؛ مثلاً با یک form مقدار «Samsung» را در دیتابیس MySQL درج می‌کنی و بعد آن را retrieve و در صفحه نمایش می‌دهی. هر سرویس روی یک port جدا مثل 3001 (frontend)، 3002 و 3003 (backendها) بالا می‌آید.
* **لینک برای جزئیات بیشتر**: [Ask AI: Project 1: PHP and MySQL Application](https://alisol.ir/?ai=Project%201%3A%20PHP%20and%20MySQL%20Application%7CUsama%20Sharif%7CLearn%20Microservices%20with%20Dockers%20%28A%20Project%20Based%20Learning%29|fa)

## موضوع ۸: پروژه ۲ – Node.js و MongoDB با REST API

* **خلاصه**: در این پروژه یک frontend می‌سازی که یک REST API نوشته‌شده با Node.js را صدا می‌زند؛ این API داده‌ها را از MongoDB می‌خواند و در قالب JSON برمی‌گرداند و frontend آن‌ها را در قالب جدول نمایش می‌دهد. علاوه‌بر این، یک رابط کاربری Mongo Express هم برای مدیریت راحت‌تر داده‌ها استفاده می‌شود. Docker Compose وابستگی‌ها را مدیریت می‌کند؛ مثلاً backend تا زمانی که دیتابیس آماده نشده، شروع به کار نمی‌کند.
* **مثال**: یک endpoint مثل `localhost:5000/movies` داده‌ها را به‌صورت JSON برمی‌گرداند و frontend روی port 3000 آن را دریافت کرده و در یک جدول لیست فیلم‌ها نمایش می‌دهد؛ ports و networks همگی در فایل YAML تنظیم شده‌اند.
* **لینک برای جزئیات بیشتر**: [Ask AI: Project 2: Node.js and MongoDB with REST API](https://alisol.ir/?ai=Project%202%3A%20Node.js%20and%20MongoDB%20with%20REST%20API%7CUsama%20Sharif%7CLearn%20Microservices%20with%20Dockers%20%28A%20Project%20Based%20Learning%29|fa)

## موضوع ۹: پروژه ۳ – Microservices چندفناوری (Multi-Technology)

* **خلاصه**: در این پروژه سیستم را گسترش می‌دهی؛ یک API در Node.js داده‌های ذخیره‌شده در MongoDB را برای دو سرویس دیگر (یکی در Flask/Python و دیگری در PHP) فراهم می‌کند تا تعامل cross-language بین سرویس‌ها را ببینی. Docker Compose همه این سرویس‌ها را کنار هم بالا می‌آورد و volumes برای نگه‌داری داده‌ها و کد استفاده می‌شود.
* **مثال**: یک API در Node.js روی مسیر `/moviesdetail` داده‌ها را برمی‌گرداند؛ سرویس Flask روی port 5000 و سرویس PHP روی port 80 همین JSON را گرفته و هر کدام آن را به شکل جدول فرمت می‌کنند. این پروژه نشان می‌دهد سرویس‌های PHP و Flask چطور می‌توانند به‌راحتی داده‌های یک سرویس Node.js را مصرف کنند.
* **لینک برای جزئیات بیشتر**: [Ask AI: Project 3: Multi-Technology Microservices](https://alisol.ir/?ai=Project%203%3A%20Multi-Technology%20Microservices%7CUsama%20Sharif%7CLearn%20Microservices%20with%20Dockers%20%28A%20Project%20Based%20Learning%29|fa)
