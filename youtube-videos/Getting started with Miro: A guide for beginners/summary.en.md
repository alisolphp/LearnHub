## Introduction to Miro
* **Summary**: Miro is an online collaborative whiteboarding platform that lets teams connect and work together from anywhere using devices with internet access. It supports features like sticky notes and text, and integrates with tools such as Google, Atlassian, and Microsoft.
* **Key Takeaway/Example**: Bring team members together on an infinite board to collaborate in real time, mimicking a physical whiteboard but with added digital capabilities.
* **Link for More Details**: [Ask AI: Introduction to Miro](https://alisol.ir/?ai=Introduction%20to%20Miro%7CMiro%7CGetting%20started%20with%20Miro%3A%20A%20guide%20for%20beginners)

## High-Level Concepts of the Miro Board
* **Summary**: The board is infinite and free-form, allowing content creation at any zoom level. It supports uploading research materials and live cursor tracking for a shoulder-to-shoulder collaboration experience, even with hundreds of users.
* **Key Takeaway/Example**: Enable live cursor tracking from the upper right-hand corner to see collaborators' movements in real time, ensuring stability during large-scale sessions like retrospectives.
* **Link for More Details**: [Ask AI: High-Level Concepts of the Miro Board](https://alisol.ir/?ai=High-Level%20Concepts%20of%20the%20Miro%20Board%7CMiro%7CGetting%20started%20with%20Miro%3A%20A%20guide%20for%20beginners)

## Navigation Tips and Tricks
* **Summary**: Use the hand tool by holding spacebar or selecting it from the object menu to move around without accidentally shifting content. Zoom with mouse or trackpad, fit to screen for a bird's eye view, and use the map icon if you get lost.
* **Key Takeaway/Example**: Undo accidental moves with Command+Z or the undo button. Switch navigation modes in settings for mouse or trackpad preferences.
* **Link for More Details**: [Ask AI: Navigation Tips and Tricks](https://alisol.ir/?ai=Navigation%20Tips%20and%20Tricks%7CMiro%7CGetting%20started%20with%20Miro%3A%20A%20guide%20for%20beginners)

## Ideation and Brainstorming
* **Summary**: Miro excels for remote ideation sessions where teams add ideas via sticky notes and text boxes. Customize colors, fonts, tags, and use emoji reactions for voting.
* **Key Takeaway/Example**: Add sticky notes from the object menu, hit Tab for new ones while typing, and change colors or add tags from the context menu. For text, select the T icon, then adjust size, color, or add hyperlinks.
* **Link for More Details**: [Ask AI: Ideation and Brainstorming](https://alisol.ir/?ai=Ideation%20and%20Brainstorming%7CMiro%7CGetting%20started%20with%20Miro%3A%20A%20guide%20for%20beginners)

## Strategy and Planning
* **Summary**: Use frames to organize content like pages in a notebook and templates for quick setups, such as company planning or remodels. Customize templates by ungrouping, editing, and regrouping.
* **Key Takeaway/Example**: Add frames from the object menu for presentations or PDF exports. Access templates via the object menu, preview, and insert pre-filled or blank versions, then Shift-click-drag to multi-select and group.
* **Link for More Details**: [Ask AI: Strategy and Planning](https://alisol.ir/?ai=Strategy%20and%20Planning%7CMiro%7CGetting%20started%20with%20Miro%3A%20A%20guide%20for%20beginners)

## Mapping and Diagramming
* **Summary**: Build diagrams like decision trees using shapes and connection lines that adapt as you move elements.
* **Key Takeaway/Example**: Select shapes from the object menu, draw by clicking and dragging, then connect with lines from blue dots on shapes. Lines auto-suggest next shapes for quick process mapping.
* **Link for More Details**: [Ask AI: Mapping and Diagramming](https://alisol.ir/?ai=Mapping%20and%20Diagramming%7CMiro%7CGetting%20started%20with%20Miro%3A%20A%20guide%20for%20beginners)

## Research and Design
* **Summary**: Upload content like Google Slides, YouTube videos, and Sheets to centralize research. Edit Google docs directly on the board, play videos inline, and navigate slides without leaving Miro.
* **Key Takeaway/Example**: Use the upload icon in the object menu to add files from device, URL, or cloud. For Google Sheets, click the pencil to edit and see updates reflect in real time on the board and source file.
* **Link for More Details**: [Ask AI: Research and Design](https://alisol.ir/?ai=Research%20and%20Design%7CMiro%7CGetting%20started%20with%20Miro%3A%20A%20guide%20for%20beginners)

## Agile Events and Integrations
* **Summary**: Organize agile workflows with integrations like Jira for two-way card syncing. Explore apps in the marketplace for tools like Zoom, Microsoft Teams, Asana, and Slack. Use Stickies Capture to digitize physical sticky notes.
* **Key Takeaway/Example**: Access apps from the object menu's three dots, add from marketplace. For Stickies Capture, upload a photo of physical notes; Miro uses OCR to convert them into editable digital stickies.
* **Link for More Details**: [Ask AI: Agile Events and Integrations](https://alisol.ir/?ai=Agile%20Events%20and%20Integrations%7CMiro%7CGetting%20started%20with%20Miro%3A%20A%20guide%20for%20beginners)

## Using Frames for Presentations
* **Summary**: Frames organize boards and enable presentations. Customize fill colors, duplicate, and reorder in the frames list. Export as PDF or present slideshow-style directly in Miro.
* **Key Takeaway/Example**: Create frames from the toolbar, add content, and move entire frames by dragging the title. Use presentation mode with arrow keys to navigate slides.
* **Link for More Details**: [Ask AI: Using Frames for Presentations](https://alisol.ir/?ai=Using%20Frames%20for%20Presentations%7CMiro%7CGetting%20started%20with%20Miro%3A%20A%20guide%20for%20beginners)

## Collaboration Features
* **Summary**: Share boards for real-time editing with hundreds of users. Lock objects, set start views, add comments, and follow collaborators' cursors.
* **Key Takeaway/Example**: Lock selected objects from the menu to prevent edits. Set start view in board settings. Add comments via the toolbar, reply with @mentions, and follow avatars to track movements during meetings.
* **Link for More Details**: [Ask AI: Collaboration Features](https://alisol.ir/?ai=Collaboration%20Features%7CMiro%7CGetting%20started%20with%20Miro%3A%20A%20guide%20for%20beginners)
